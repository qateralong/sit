# Sit

Server-side Fabric mod: sit on stairs, slabs or another player's head.

## Features

- Right-click stairs, slabs or another player's head with an empty hand to sit.
- Shift to get up.
- Works without a client mod.

## Compatibility

Minecraft 1.21.1, Fabric Loader and Fabric API. Runs on the server; players need no client mod.

## Build

```bash
./gradlew build
```

The jar appears in `build/libs/`.
